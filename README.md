# Chogsticks

Your Chog gets paid when the internet uses it.

Every Chog Genesis NFT on Monad becomes a sticker pack made from its own art. Anyone can send it in Discord with `/chog`. Each send is credited to that token, and every week the current holder claims $CHOG based on how much their Chog was used.

## Run locally

```
cp .env.example .env.local
npm install
npm run dev
```
